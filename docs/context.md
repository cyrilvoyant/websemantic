# Origine et périmètre

La démonstration présentée par Nicolas Fichaux le 2 octobre 2026 a motivé l’étude des liens entre une demande, les informations nécessaires, les services disponibles et les données utiles. WebSemantic applique cette démarche à l’exécution de logiciels scientifiques existants.

Le travail porte sur trois questions : rendre les paramètres compréhensibles, préserver la provenance des choix et qualifier les résultats calculés. L’ontologie relie les objectifs, les variables, les configurations et les sorties ; elle ne remplace ni le modèle numérique ni sa validation scientifique.

TLS sert de premier cas de développement. Les scénarios sont fictifs et les constantes du modèle restent à calibrer pour une étude de terrain. Les sources géographiques peuvent documenter une hypothèse, mais ne déterminent pas automatiquement la géométrie, les probabilités d’événements ou les pointes de trafic d’un tunnel.

Le positionnement principal est l’informatique pour l’ingénierie et l’utilisabilité du logiciel de recherche. L’application à des modèles environnementaux constitue une perspective ; aucune démonstration d’observation de la Terre n’est revendiquée.
