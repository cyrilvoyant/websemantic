# Choix de conception

- Conserver les sources et déploiements des simulateurs.
- Définir les paramètres et leurs unités dans le descripteur.
- Proposer les hypothèses puis demander leur acceptation.
- Privilégier les phrases ; garder les raccourcis facultatifs.
- Fixer la graine à 42 sauf demande explicite.
- Conserver configuration, révision et provenance avec les résultats.
- Séparer le dépôt public des configurations privées.
