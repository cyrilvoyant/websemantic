# Décisions du projet

| Sujet | Décision retenue |
|---|---|
| Objet | Améliorer l’accès, la configuration et la qualification des sorties de logiciels scientifiques |
| Données | Scénarios synthétiques ; aucun jeu de mesures de terrain disponible |
| Sources des modèles | Dépôts et déploiements existants conservés ; adaptateurs dans un dépôt séparé |
| Première intégration | TLS, fixé à une révision contrôlée |
| Transfert | LQL-Equiv et pvlib prévus ; aucune intégration conversationnelle annoncée comme terminée |
| Valeurs manquantes | Proposition traçable puis acceptation, sans ajout silencieux d’hypothèses physiques |
| Réglage technique | Graine initiale 42, conservée sauf modification explicite |
| Interaction | Phrases naturelles en priorité ; raccourcis facultatifs |
| Diffusion | Code public sans clé ; package de validation privé distinct |
| Licence | PolyForm Noncommercial 1.0.0 pour les révisions courantes ; licences des composants conservées |
| Publication | Un article présentant le cadre et son évaluation ; protocole détaillé séparé du texte principal |

Le gel du cœur pour l’étude de transfert reste à déclarer sur une révision identifiée. La revue cible, le profil pvlib et les informations d’affiliation complémentaires restent à préciser. Les décisions et les essais de développement sont consignés dans le journal de travail conservé séparément des documents de validation.
